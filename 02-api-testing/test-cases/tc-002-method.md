# TC-002: Проверка обработки неверного HTTP-метода

## 📋 Основная информация

| Поле | Значение |
|------|----------|
| **ID** | TC-002 |
| **Название** | Проверка обработки неверного HTTP-метода (405) |
| **Приоритет** | Medium |
| **Тип** | API / Обработка ошибок |
| **Компонент** | `/api/chat/list` |
| **Статус** | ✅ Выполнен |
| **Инструмент** | Postman |

---

## ✅ Предусловия

| № | Условие |
|---|---------|
| 1 | Cookie `aurora_session` добавлена в заголовки Postman |
| 2 | Известен рабочий эндпоинт `GET /api/chat/list` |

---

## 🔁 Шаги выполнения

| № | Действие | Ожидаемый результат | Фактический результат | Статус |
|---|----------|---------------------|------------------------|--------|
| 1 | `GET /api/chat/list` с Cookie | 200 OK | 200 OK | ✅ Passed |
| 2 | `PUT /api/chat/list` с Cookie | 405 Method Not Allowed | 405 Method Not Allowed | ✅ Passed |
| 3 | Проверить тело ответа | `{"reason": "method_not_allowed", "status": "error"}` | Соответствует | ✅ Passed |
| 4 | `DELETE /api/chat/list` с Cookie | 405 Method Not Allowed | 405 Method Not Allowed | ✅ Passed |
