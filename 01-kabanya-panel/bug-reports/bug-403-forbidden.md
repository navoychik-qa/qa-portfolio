# Баг: 403 Forbidden при загрузке административных данных

## 📋 Основная информация

| Поле | Значение |
|------|----------|
| **ID** | BUG-001 |
| **Severity** | Critical |
| **Priority** | ASAP |
| **Статус** | ✅ Исправлен, верифицирован |
| **Окружение** | Chrome 120, Windows 10, роль Administrator |

---

## 📝 Описание

При открытии страницы «Главное» (`/bsettings`) и вкладки «Пользователи» (`/user`) 
под авторизованным пользователем с ролью **admin** запросы к API возвращают 403 Forbidden.

---

## 🔁 Шаги воспроизведения

1. Войти на `https://panel.kabanya.ru` под ролью admin
2. Открыть DevTools → Network → Fetch/XHR
3. Перейти на страницу «Главное» или «Пользователи»
4. Обновить страницу (F5)
5. Найти запрос `GET /api/admin/users` или `GET /api/admin/permissions`

---

## ❌ Фактический результат

- Сервер возвращает **403 Forbidden**
- Виджеты не загружаются
- В консоли ошибки `Uncaught (in promise) Error`
- Фильтры в левой панели не работают

---

## ✅ Ожидаемый результат

- Сервер возвращает **200 OK**
- Виджеты и список пользователей отображаются
- Фильтры работают корректно

---

## 💬 Комментарии

**Разработчик (fix):**  
> Причина: в дефолтах прав Administrator имел `admin: false`. 
> Исправлено: `effective_permissions()` объединяет права с дефолтами, 
> держит инварианты: Developer — всегда всё, Administrator — всегда admin.

**Тестировщик (верификация):**  
> Проверил после исправления: запросы возвращают 200 OK, 
> ошибок в консоли нет, список пользователей и фильтры работают.
