# TC-002: Проверка загрузки административных данных на странице «Главное»

## 📋 Основная информация

| Поле | Значение |
|------|----------|
| **ID** | TC-002 |
| **Название** | Проверка загрузки административных данных на странице «Главное» |
| **Приоритет** | High |
| **Тип** | Функциональный / Права доступа |
| **Компонент** | Страница «Главное», API `/api/admin/*` |
| **Статус** | ✅ Выполнен |
| **Связанный баг** | BUG-001 |

---

## ✅ Предусловия

| № | Условие |
|---|---------|
| 1 | Пользователь авторизован на сайте `panel.kabanya.ru` |
| 2 | Роль пользователя — Administrator |
| 3 | Доступен браузер с DevTools (Opera / Chrome) |

---

## 🔁 Шаги выполнения

| № | Действие | Ожидаемый результат | Фактический результат | Статус |
|---|----------|---------------------|------------------------|--------|
| 1 | Войти на `panel.kabanya.ru` под ролью admin | Успешная авторизация, открыт дашборд | Авторизация успешна | ✅ Passed |
| 2 | Перейти на страницу «Главное» (`/bsettings`) | Страница загружается, виджеты отображаются | Страница открывается | ✅ Passed |
| 3 | Открыть DevTools → Network → Fetch/XHR | Список запросов отображается | Открыто | ✅ Passed |
| 4 | Обновить страницу (F5) | Все виджеты загружаются, запросы возвращают 200 OK | Виджеты **не загружаются** | ❌ Failed |
| 5 | Проверить статус запроса `GET /api/admin/users` | 200 OK | **403 Forbidden** | ❌ Failed |
| 6 | Проверить статус запроса `GET /api/admin/permissions` | 200 OK | **403 Forbidden** | ❌ Failed |
| 7 | Открыть DevTools → Console | Ошибок нет | Ошибка `Uncaught (in promise) Error...` | ❌ Failed |
| 8 | Перейти во вкладку «Пользователи» | Список пользователей загружен | Список **не загружается** | ❌ Failed |
| 9 | Проверить фильтры (Чистые, В муте, Забанены и т.д.) | Фильтры работают | **Не работают** | ❌ Failed |
| 10 | Проверить роль Moderator: `/admin` | 403 Forbidden | 403 Forbidden | ✅ Passed |
| 11 | Проверить роль Moderator: `/kbase` | 200 OK | 200 OK | ✅ Passed |

---

## 📊 Итог

| Всего шагов | Passed | Failed |
|-------------|--------|--------|
| 11 | 5 | 6 |

**Вывод:** под ролью Administrator административные данные **не загружаются** — сервер возвращает 403 Forbidden на запросы `/api/admin/*`. Виджеты на странице «Главное» и список пользователей недоступны. Обнаружен баг — см. [BUG-001](../bug-reports/bug-403-forbidden.md).
